Fausth in the browser

The TypeScript engine of spec v0.4 in one page: it replays the conformance fixtures, and it plays a harness live.

Conformance replay

Each fixture's recorded files run through the engine here; the log and the rendered requests must equal the expected files byte for byte. The Python engine reproduces the same files, so a match here is a match with Python.

The harness below is examples/chess/harness.yaml, the spec's §2 example, the same file the Python host runs. Its tools run on chess.js. The endpoint must accept calls from a browser (OpenRouter does; the KIT gateway allows only its own origin). The key stays in this page's memory and is sent only to the endpoint.
